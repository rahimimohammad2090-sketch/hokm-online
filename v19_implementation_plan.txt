نسخه 19v — شروع پیاده‌سازی واقعی

هدف:
تبدیل اسکلت مراحل قبلی به ساختار قابل اتصال به اپلیکیشن واقعی.

اجزای آماده‌شده:
1. هسته ساده Node.js
2. ساخت اتاق با کد ۶ کاراکتری
3. ورود بازیکن به اتاق
4. وضعیت عمومی اتاق
5. health check سرور
6. قرارداد اولیه API

برای انتشار واقعی در مرحله بعد:
- WebSocket واقعی برای بازی لحظه‌ای
- PostgreSQL یا دیتابیس مناسب
- احراز هویت امن
- TLS/HTTPS
- Rate limiting
- لاگ و مانیتورینگ
- کلاینت Android
- تست همزمانی چهار بازیکن
